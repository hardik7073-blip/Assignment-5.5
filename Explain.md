### Design Choices

1. I used navy blue, emerald green, and white to create a consistent and professional college club website.
2. External CSS keeps the styling separate from HTML and makes all pages easier to maintain.
3. CSS variables provide reusable colors and spacing values throughout the website.
4. Classes, element selectors, and grouping selectors help style navigation, headings, buttons,    forms, and tables consistently.
5. Responsive CSS and Chrome DevTools help improve mobile usability and identify styling issues.
